JavaScriptでイベントに処理を登録する手順

addEventListenerは、「指定したイベントが起きたときに、この処理を実行する」と登録するためのメソッドです。 ここでは、ボタンをクリックしたときに四角形をアニメーションさせる例で説明します。

問題を解く

イベント登録の主な方法

JavaScriptには、イベントへ処理を登録する方法がいくつかあります。 普段はaddEventListenerを基本にしつつ、既存コードや用途に合わせて選びます。

方法例特徴
addEventListener()button.addEventListener("click", handler)最も推奨される方法。複数の処理を登録できる
イベントハンドラプロパティbutton.onclick = handlerシンプルだが、同じイベントに1つの処理しか保持できない
HTML属性<button onclick="handler()">HTML内に直接書く方法。保守性が下がるため非推奨寄り
jQueryの .on()$("#btn").on("click", handler)jQueryを使っている場合の一般的な方法
インラインの無名関数button.addEventListener("click", () => {...})小さな処理をその場で書ける
イベント委譲parent.addEventListener("click", e => {...})動的に追加される要素にも対応しやすい
once オプションaddEventListener("click", handler, { once: true })1回だけ実行したいときに使う
capture オプションaddEventListener("click", handler, { capture: true })キャプチャフェーズで処理したいときに使う
passive オプションaddEventListener("touchmove", handler, { passive: true })スクロール系イベントで、ブラウザの最適化を助けたいときに使う

イベント登録の流れ

カードを選ぶと、右側にその手順のコードと説明が表示されます。

Step 1

要素を取得する

ここでは、クリックされるボタンと、アニメーションさせる青い四角形を取得しています。取得した要素は変数に入れておくと、あとから処理の中で使えます。

const button = document.getElementById("startButton");
const box = document.getElementById("box");

全体のコード

ボタンのクリックイベントと、アニメーション終了イベントの両方に処理を登録しています。

const button = document.getElementById("startButton");
const box = document.getElementById("box");

button.addEventListener("click", () => {
  box.classList.remove("animate");

  void box.offsetWidth;

  box.classList.add("animate");
});

box.addEventListener("animationend", () => {
  box.classList.remove("animate");
});

よく使うイベント名

第1引数には、文字列でイベント名を指定します。

click
クリックされたとき
input
入力欄の内容が変わったとき
change
選択や入力内容が確定したとき
mouseover
マウスが要素の上に乗ったとき
keydown
キーボードのキーが押されたとき
animationend
CSSアニメーションが終わったとき

動作イメージ

ボタンを押すと、クリックイベントに登録された処理が実行されます。 処理の中では、青い四角形にアニメーション用のクラスを付け直しています。

クリック回数: 0

まとめ

JavaScriptでイベントに処理を登録するときは、「要素を取得する」、「イベント名を指定する」、「実行する関数を書く」という順番で考えると分かりやすくなります。
