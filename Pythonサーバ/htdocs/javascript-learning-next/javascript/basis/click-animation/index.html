クリックアニメーション

class操作のサンプル切り替え

React + Tailwind CSS

iframe内でクリックアニメーションを実行するサンプル

ボタンをクリックすると、iframe内の青い四角形にCSSアニメーションが実行されます。 このページでは、アニメーションを何度も再実行するためのclassList.remove、offsetWidth、animationendの役割を確認できます。

実行結果

iframe内のボタンをクリックすると、青い四角形がバウンドします。 連続でクリックしても、アニメーションが最初から再生されます。

解説

1. クリック時にクラスを外す

クリックされた瞬間に、まずanimateクラスを外します。これは、前回のアニメーションでクラスが残っている場合でも、 アニメーションを最初からやり直せるようにするためです。

2. offsetWidthで再計算させる

void box.offsetWidthは、ブラウザに現在の状態をいったん確定させるための処理です。 これにより、「クラスを外した後に、もう一度付ける」という変化を ブラウザが正しく認識できます。

3. クラスを付け直して再生する

その後、animateクラスを付け直します。このクラスに設定されたanimationが有効になり、CSSアニメーションが最初から再生されます。

クリック時の remove の役割

クリック時のbox.classList.remove("animate")は、アニメーションをその場でリセットするための処理です。 特に、アニメーション中にもう一度クリックされた場合に効果があります。

animationend側の remove の役割

animationend側のremoveは、アニメーション終了後に状態をきれいに戻すための処理です。 CSSアニメーションが最後まで終わった直後に実行されます。

クリック時のremoveは「今すぐ再スタートするため」、animationend側のremoveは「終わったあとに状態を戻すため」です。 目的が違うため、両方書いておくと連続クリックにも強い安定したコードになります。

iframeに入れているコード

React側では、このHTML文字列をiframeのsrcDocに渡しています。 コメントも含めて確認できます。

<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8" />
  <title>クリックでアニメーション</title>
  <style>
    body {
      font-family: sans-serif;
      padding: 20px;
    }

    .box {
      width: 120px;
      height: 120px;
      background: #4f8cff;
      border-radius: 12px;
      margin: 40px 0;
    }

    /*
      animateクラスが付いたときにCSSアニメーションが実行されます。
      animationの時間が0.6sなので、約0.6秒後にanimationendイベントが発火します。
    */
    .animate {
      animation: bounce 0.6s ease;
    }

    @keyframes bounce {
      0% {
        transform: translateY(0);
      }
      30% {
        transform: translateY(-30px);
      }
      60% {
        transform: translateY(10px);
      }
      100% {
        transform: translateY(0);
      }
    }
  </style>
</head>
<body>
  <button id="startButton">アニメーション開始</button>

  <div id="box" class="box"></div>

  <script>
    const button = document.getElementById("startButton");
    const box = document.getElementById("box");

    button.addEventListener("click", () => {
      /*
        クリックされた瞬間に、いったんanimateクラスを外します。

        これは、前回のアニメーションでanimateクラスが残っている場合や、
        アニメーション中にもう一度クリックされた場合でも、
        アニメーションを最初からやり直せるようにするためです。
      */
      box.classList.remove("animate");

      /*
        offsetWidthを読むことで、ブラウザに現在の状態を再計算させます。

        これを入れないと、
        「クラスを外す」
        「すぐ同じクラスを付ける」
        という処理がまとめて扱われてしまい、
        アニメーションが再スタートしないことがあります。

        void は、offsetWidthの値そのものは使わないことを表しています。
      */
      void box.offsetWidth;

      /*
        animateクラスを付け直します。

        ここでCSSの animation: bounce 0.6s ease; が有効になり、
        アニメーションが最初から再生されます。
      */
      box.classList.add("animate");
    });

    /*
      animationend は、CSSアニメーションが最後まで再生された直後に発火します。

      このサンプルでは、bounceアニメーションが0.6秒で終わるため、
      animateクラスを付けてから約0.6秒後にこの処理が実行されます。
    */
    box.addEventListener("animationend", () => {
      /*
        アニメーション終了後にanimateクラスを外します。

        これにより、要素は「アニメーションしていない状態」に戻ります。
        次回クリックしたときに、また自然にanimateクラスを付け直せます。
      */
      box.classList.remove("animate");
    });
  </script>
</body>
</html>
