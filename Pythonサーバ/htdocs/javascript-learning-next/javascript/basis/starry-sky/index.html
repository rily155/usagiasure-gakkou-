星空アニメーションの仕組み

HTMLで星を配置する領域を用意し、CSSで星の見た目と点滅を設定し、 JavaScriptで星をランダムに生成しています。

SOURCE CODE

starrysky.html

HTMLを別画面で開く

ソースコードを読み込んでいます。

1

DOCTYPE宣言

<!DOCTYPE html>

解説

この文書がHTML5で記述されていることをブラウザに伝えます。

2

html要素

<html lang="ja">

解説

HTML文書全体を囲む要素です。lang="ja"は、このページの言語が日本語であることを示します。

3

メタ情報

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">

解説

charsetは文字コードを指定し、viewportはスマートフォンなどの画面幅に合わせて表示するための設定です。

4

CSS変数

:root {
  --hue: 230;
  --sky-from: hsl(var(--hue) 35% 6%);
  --sky-to: hsl(var(--hue) 55% 12%);
}

解説

ページ全体で利用する色をCSS変数として定義しています。--hueの値を変更すると、空全体の色相を調整できます。

5

背景のグラデーション

body {
  margin: 0;
  background: radial-gradient(
    1200px 600px at 50% -20%,
    var(--sky-to),
    var(--sky-from) 60%
  ) fixed;
  overflow: hidden;
}

解説

bodyの余白を削除し、放射状グラデーションで夜空を表現しています。overflow: hiddenによって画面外の要素を非表示にします。

6

星を配置する領域

.sky {
  position: fixed;
  inset: 0;
}

解説

sky要素を画面全体に固定しています。inset: 0はtop、right、bottom、leftをすべて0にする指定です。

7

星の見た目

.star {
  position: absolute;
  border-radius: 50%;
  background: radial-gradient(
    circle,
    rgba(255,255,255,.95) 0 40%,
    rgba(255,255,255,0) 70%
  );
  opacity: var(--base-opacity, .65);
}

解説

星を絶対配置し、border-radiusで円形にしています。放射状グラデーションによって中心が明るく、外側が透明になる光を表現しています。

8

星の点滅アニメーション

.star {
  animation: twinkle var(--twinkle, 2.2s)
    ease-in-out infinite;
  animation-delay: calc(var(--delay, 0s) * -1);
}

解説

星ごとに異なるアニメーション時間と開始位置を指定しています。負のanimation-delayを使うことで、最初から星がばらばらに点滅します。

9

点滅の変化

@keyframes twinkle {
  0%, 100% {
    opacity: .6;
    transform: scale(1);
  }

  40% {
    opacity: .2;
  }

  70% {
    opacity: 1;
    transform: scale(1.1);
  }
}

解説

透明度と大きさを時間に応じて変化させています。星が暗くなった後、少し大きく明るくなる動きを繰り返します。

10

星空を表示するHTML

<div class="sky"></div>
<footer class="credits">
  CSS Twinkling Stars Demo
</footer>

解説

sky要素の中にJavaScriptで星を追加します。footerは画面下部にクレジットを表示するための要素です。

11

星の数

const sky = document.querySelector(".sky");
const STAR_COUNT = 220;

解説

document.querySelectorで星を配置するsky要素を取得します。STAR_COUNTには生成する星の数を指定します。

12

ランダムな数値の生成

const rand = (min, max) =>
  Math.random() * (max - min) + min;

解説

指定された最小値から最大値までのランダムな小数を生成する関数です。

13

星の生成

for (let i = 0; i < STAR_COUNT; i++) {
  const star = document.createElement("span");
  star.className = "star";

  star.style.left = `${rand(0, 100)}%`;
  star.style.top = `${rand(0, 100)}%`;

  sky.appendChild(star);
}

解説

for文を使って220個のspan要素を作成します。leftとtopをランダムに指定し、画面内のさまざまな位置に星を配置します。

14

星ごとの設定

star.style.width =
  star.style.height =
    `${rand(1, 3)}px`;

star.style.setProperty(
