JavaScript URL API

パネルを閉じるときのURLクエリ削除

詳細パネルを閉じるとき、URLのクエリを全部消すと検索条件まで失われます。 `URL` と `searchParams` を使うと、地図やパネル表示に使ったパラメータだけを削除できます。

動作サンプル

ブラウザの実URLは変更せず、下の表示だけを更新して違いを確認できます。

現在のURL

/properties?keyword=空き家&area=東京&id=123&lat=35.1&lng=139.1

修正前

修正前は、パネルを閉じるときに pathname だけへ戻していました。

function closePanelBefore() {
  location.href = location.pathname;
}

/properties?keyword=空き家&area=東京&id=123&lat=35.1&lng=139.1 から実行すると、結果は /properties になります。

この場合、地図用の `id`、`lat`、`lng` だけでなく、検索条件の `keyword` や `area` まで消えてしまいます。

修正後

修正後は、現在のURLを new URL() で扱い、 不要なパラメータだけを削除します。

function closePanelAfter() {
  const url = new URL(location.href);

  url.searchParams.delete("id");
  url.searchParams.delete("lat");
  url.searchParams.delete("lng");

  history.replaceState(null, "", url.pathname + url.search);
}

同じURLから実行すると、結果は /properties?keyword=空き家&area=東京 になります。

検索条件を残したまま、パネル表示に使った `id`、`lat`、`lng` だけを削除できます。

使うAPI

URL

文字列のURLを、pathnameやsearchParamsに分けて扱えます。

searchParams.delete

指定したクエリキーだけを削除できます。

history.replaceState

ページ遷移せずにブラウザのURL表示を置き換えます。
