ジャンプゲーム（説明画面とメイン画面を分離）

■ フォルダー構成
説明画面/index.html : 操作説明（3ページ）
メイン/index.html : メインゲーム画面
メイン/asureB.css : 画面デザイン
メイン/asureC.js : ゲーム処理・当たり判定
メイン/images/ : ゲーム画像

■ 起動方法
1. ZIPを展開します。
2. 「ジャンプゲーム/説明画面/index.html」を開きます。
3. 説明を最後まで読み、「メインゲームへ」を押します。
4. メイン画面で「ゲームスタート！」を押すとゲームが始まります。

フォルダー構成を変更せずに使用してください。
