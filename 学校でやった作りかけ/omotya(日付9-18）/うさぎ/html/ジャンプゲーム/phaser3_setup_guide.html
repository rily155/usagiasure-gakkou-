Phaser 3 導入手順

Node.js・npm・Viteを使わず、Phaser 3の配布ファイルをプロジェクト内の lib フォルダに保存する方法です。Gitにもライブラリ本体を登録できます。

1. Phaser本体を取得する

  1. Phaser 3.90.0 の phaser.min.js を開く。
  2. ブラウザの「名前を付けて保存」でファイル名を phaser.min.js にする。
  3. 公式リリース情報：Phaser v3.90.0。

2. フォルダを用意する

usagi-game/
├── index.html
├── lib/
│   └── phaser.min.js
├── js/
│   └── main.js
└── images/

3. index.html を作成する

<!doctype html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>うさぎゲーム</title>
</head>
<body>
  <div id="game"></div>
  <script src="./lib/phaser.min.js"></script>
  <script src="./js/main.js"></script>
</body>
</html>

Phaser本体を、ゲームのJavaScriptより先に読み込みます。

4. js/main.js を作成する

class GameScene extends Phaser.Scene {
  constructor() {
    super('GameScene');
  }
  create() {
    this.player = this.add.rectangle(100, 200, 40, 40, 0x2563eb);
    this.cursors = this.input.keyboard.createCursorKeys();
  }
  update(time, delta) {
    const speed = 200 * delta / 1000;
    if (this.cursors.left.isDown) this.player.x -= speed;
    if (this.cursors.right.isDown) this.player.x += speed;
  }
}

new Phaser.Game({
  type: Phaser.AUTO,
  parent: 'game',
  width: 800,
  height: 450,
  backgroundColor: '#dbeafe',
  scene: GameScene
});

5. ブラウザで動作確認する

  1. 開発時はVS CodeのLive ServerなどでローカルHTTPサーバーを起動する（Node.jsのインストールは不要）。
  2. 表示されたURLでゲームを開き、左右キーで青い四角形が動くことを確認する。
  3. F12 → Consoleで Phaser.VERSION と入力し、3.90.0 と表示されれば読み込み成功。

HTMLファイルを直接開く file:// 方式では、後から画像・JSONなどを読み込む際にブラウザの制限で失敗する場合があります。HTTPサーバーでの確認を推奨します。

6. Gitに保存する

git init
git add index.html js/main.js lib/phaser.min.js
git commit -m "Phaser 3.90.0 を導入"

lib/phaser.min.js もGitに含まれます。別のPCでクローンしても npm install は不要です。

7. 公開する

index.html、js/、lib/、images/ をそのままXserverなどのWebサーバーにアップロードします。ビルドは不要です。

補足：Phaser 3.90.0を使用する手順です。ライブラリを更新する際は配布ファイルの差し替えと動作確認を行ってください。
