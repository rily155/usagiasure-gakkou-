01 開発方針

外部のエミュレーターライブラリやフレームワークを使わず、HTML・CSS・JavaScript・Canvasでゲーム機を再現する。まず初代GBを実装し、動作テストを経てGBCに拡張する。最終目標は手元の適法なクリスタルROMを起動すること。

既存のPythonWebServerは静的ファイルを配信するだけでよい。ゲーム処理はブラウザ内で実行する。現在のPhaser製RPGとは独立したアプリとして管理する。

 document.querySelector('#rom').onchange = async (event) => {
   const file = event.target.files[0];
   if (!file) return;
   const rom = new Uint8Array(await file.arrayBuffer());
   console.log('ROM size:', rom.length);
 };

ローカルファイル選択ならROMをWebサーバへアップロードする必要はない。Canvasは整数倍拡大し、CSSの image-rendering: pixelated を指定する。

04 CPU実装の基本

PC（プログラムカウンタ）から命令を取得し、レジスタを更新して消費クロックを返す。以下は学習用の一部命令のみの実装。

class CPU {
  constructor(bus) {
    this.bus = bus;
    this.a = 0; this.f = 0; this.pc = 0;
  }
  fetch() {
    const value = this.bus.read(this.pc);
    this.pc = (this.pc + 1) & 0xffff;
    return value;
  }
  step() {
    const op = this.fetch();
    switch (op) {
      case 0x00: return 4; // NOP
      case 0x3e: this.a = this.fetch(); return 8;
      case 0x3c: { // INC A
        const old = this.a;
        this.a = (old + 1) & 255;
        this.f = (this.f & 0x10) |
          (this.a === 0 ? 0x80 : 0) |
          ((old & 15) === 15 ? 0x20 : 0);
        return 4;
      }
      default: throw Error('Unsupported opcode: ' + op);
    }
  }
}

本実装では全有効命令・CB拡張命令、割り込み、HALT、STOP、条件分岐、正確なタイミング等が必要。起動ROMを使わない場合は機種に応じた初期状態も設定する。

実行ループ

CPU.step() → 消費クロック
↓
Timer / PPU / APU を進める・割り込み処理
↓
フレーム完成 → Canvasに転送 → 次のフレーム

requestAnimationFrame は画面更新の契機として使い、実機時間はクロックで管理する。精度向上には命令内のバスアクセス単位の同期も必要。

06 ゲームのリポジトリとビルド

pretのプロジェクトはゲームを解析し、ソースとして再構築する非公式プロジェクト。エミュレーターとは別物である。

リポジトリ対象主言語 / 出力
pokered赤・青ASM / GB
pokecrystalクリスタルASM / GBC
pokefireredファイアレッド・リーフグリーンC中心 / GBA
pokeemeraldエメラルドC中心 / GBA
pokeheartgoldハートゴールド・ソウルシルバーC等 / DS

GBA・DS用ROMはGB/GBCエミュレーターでは動作しない。

クリスタルのビルド概要（Windows + WSL）

# PowerShell
wsl --install -d Ubuntu

# Ubuntu
sudo apt update
sudo apt install git make gcc
git clone https://github.com/pret/pokecrystal
cd pokecrystal
# INSTALL.md に従い、指定版RGBDSと依存関係を導入
make

ビルド手順（INSTALL.md） / RGBDS導入。必要なバージョンと依存関係はリポジトリの指示を優先する。

pokecrystal ソース (ASM・データ)
↓ RGBDS + Make
pokecrystal.gbc
↓
自作 JavaScript エミュレーター（GBC対応後）

出力はWindowsのEXEではない。Windowsアプリ化はエミュレーターのWeb UIをTauri等で包む別工程になる。
